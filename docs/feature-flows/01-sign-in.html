Server · FastAPI on Render
  1. The browser signs in with Supabase Auth directly (supabase-js): an emailed 8-digit code or link, or an anonymous guest session. No server call.
  2. Every API call carries the Supabase access token; app/auth.py asks Supabase whose it is (cached briefly). An email on ALLOWED_EMAILS is a full account; everyone else, and guests, use the free models.
  3. “Sign in on your phone”: POST /api/handoff (already signed in) returns an 8-digit code and a QR link. Codes live in server memory for 10 minutes and work once.
  4. The phone scans or types it: POST /api/handoff/redeem asks Supabase for a one-time token (admin generate_link, no email sent); the phone finishes with verifyOtp.
  5. Wrong codes are limited: 8 per address and 200 overall per 10 minutes.
