Architecture

Every agent, and the tools it has

Twelve agents in the app, plus the eval judges used in development. Only one of them calls a tool itself; the rest work with what the app gathers and does around them.
MODEL-CALLED TOOL the model decides when to use it   STRUCTURED OUTPUT reply forced into a JSON schema   VISION reads images   APP-RUN TOOL the server or browser does it, before or after the model   TEXT ONLY text in, text out

Making a retreat background jobs on Render; model = the retreat's planning or writing model (Claude Opus 5.5 by default, Muse Glimmer free)

The planner

Planning model · plan.md + plan_rules.md

The document's text, its images and scanned pages, earlier retreats in a series

  • VISION matches paintings to days, transcribes scanned pages
  • STRUCTURED OUTPUT the plan schema (Claude); free models reply in JSON text
  • APP-RUN if a free model's plan is too long, it marks each passage's first and last words and the app copies the passage from the document
Days, passages, graces, focus, image choices→ retreats.data (the plan)

Idea to passages

Planning model · inspiration.md

The idea in words, the number of days, an optional photo

  • VISION reads verses in the photo
  • STRUCTURED OUTPUT one reference a day
  • APP-RUN bible-api.com fetches the World English Bible text, so no scripture is written by a model
A source document→ the planner

For the heart

Writing model · heart_companion.md or heart_christ.md

The day's passage, grace, focus, painting description; what earlier days said; the coming readings

  • TEXT ONLY script inside <script> tags, length set by the voice
The reflection script→ recorded; read by the deep dive and the guidance

Search query writer

Free model (Muse Glimmer) · research.md (queries)

The day's context

  • TEXT ONLY three search queries
  • APP-RUN the six search services run them at once: Brave Search, Brave Answers, Exa, Tavily, Firecrawl, Linkup; results interleaved, deduplicated, up to 20
Web research→ the deep dive; logged; the research page

The deep dive

Writing model · deep_dive.md + deep_format.md

The day, the heart reflection, the web research, earlier days

  • MODEL-CALLED TOOL web_search (Anthropic server tool, up to 5 searches), Claude only, to check claims and find better sources
  • FREE MODELS no tool: they write only from the research given, and cite only pages that came back
Script and sources→ recorded; sources and searches on the research page

The spoken guidance

Writing model · guide_tailor.md + guide_lines.md

The default guiding lines, the heart reflection, the deep dive

  • STRUCTURED OUTPUT one line per slot
  • APP-RUN checks each line: the grace kept word for word, a sensible length, else the default line
Tailored lines→ recorded

Talking it over Talk now and Talk it over

The companion, live voice

OpenAI gpt-live-1 (WebRTC) or xAI grok-voice-latest (WebSocket) · companion.md

Built by talk.context: your notes and wishes, the time where you are, when you last talked, its memory, recent transcripts, the retreat day by day

  • NO FUNCTION TOOLS speech in, speech out, in one model
  • APP-RUN the provider detects turns and lets you interrupt; the server starts the session (the key stays on the server) and hangs up at the time limit
The conversation, spoken→ transcript saved; memory

The companion, taking turns

Brain: Muse Glimmer (free), Claude Fable 5.1 / Opus 5.5 / Haiku 4.5, or OpenAI GPT-5.5 / 5.4 mini · + companion_spoken.md

The same context, and the conversation so far

  • TEXT ONLY one short reply per turn (Claude's context is cached)
  • APP-RUN the browser's speech recognition hears you; Microsoft voices (edge-tts) speak each sentence
One reply at a time→ spoken; transcript saved

The companion's memory

Claude Opus 5.5 or free model · companion_memory.md

The existing memory and older transcripts

  • TEXT ONLY a condensed memory
Memory notes→ conversations.json; the next conversation

Eval judges (development)

A: Claude Opus 5.5 + GPT-6 Sol · B: DeepEval G-Eval (Grok 4.7) + Jev · eval_judge*.md

A piece or conversation written by a contestant model, blind

  • STRUCTURED OUTPUT 1-7 scores on the rubric
  • APP-RUN Jev answers with calibrated probabilities (not an LLM)
Scores→ evals/runs, the comparison report

Every agent also gets

  • The background (background.md): the Exercises, retreats, lectio divina, how a day is prayed here
  • Your About me notes (about_the_person.md), unless you asked for a general retreat
  • Your own version of its prompt, if you made one on the Agents page
  • Writers also get the house style: writing for the ear and for prayer

Around every call

  • Logged to llm_calls: what was sent, what came back, tokens, cost, time
  • Keys stay on the server; the browser never sees them
  • Voices are tools of the app, not the agents: Microsoft (edge-tts, free) and ElevenLabs, with word timings
  • Prompts live in app/agent_prompts/; the Agents page lets each person read and change them
